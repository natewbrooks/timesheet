# Timesheet

Built for tracking time to enable an unstructured lifestyle.

Each sheet gets a notes page for the week and individual days. Autosaves as you go.

**Run:**
```
cd timesheet
chmod +x install.sh
./install.sh
```

**Features:**
- Weekly sheets with drag-and-drop time entries
- Per-day and per-sheet notes
- Earnings estimate (gross + net) based on hourly or salary after tax
- Progress bar toward your weekly target
- CSV + PDF export
- Deadline countdown so you know how much to log per day
